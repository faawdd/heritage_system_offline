## 🎨 样式系统架构

```
CSS 层次结构：
┌────────────────────────────────────────────────┐
│ 浏览器默认样式（User Agent Stylesheet）        │
└────────────────────────────────────────────────┘
                        ↓
┌────────────────────────────────────────────────┐
│ SimpleUI 框架样式                              │
│ └─ Element UI 样式库                          │
│    └─ 表格、菜单、按钮基础样式                 │
└────────────────────────────────────────────────┘
                        ↓
┌────────────────────────────────────────────────┐
│ Django Admin 默认样式                          │
│ └─ admin/css/base.css                         │
│    └─ 表单、列表、按钮样式                     │
└────────────────────────────────────────────────┘
                        ↓
┌────────────────────────────────────────────────┐
│ 项目自定义样式                                  │
│ ├─ /static/admin/css/simpleui_custom.css      │
│ │  └─ 字体堆栈、表格美化、表单调整            │
│ │
│ └─ 内联样式 <style> 块                        │
│    ├─ templates/admin/*.html 中               │
│    ├─ templates/public/app_showcase.html      │
│    └─ 各页面特定样式                          │
└────────────────────────────────────────────────┘

📊 CSS 特异性：
           内联样式 <style>
                 ↑
            100%  !important
                 ↑
         ID 选择器 #
                 ↑
    类/属性选择器 .class
                 ↑
         元素选择器 div
```

│               │ 存储 InspectionRecord                          │
